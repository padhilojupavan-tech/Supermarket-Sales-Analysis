# Supermarket Sales Analysis Dashboard

## Project Overview

This project analyzes supermarket sales data using Microsoft Power BI. The goal is to understand sales performance across products, categories, cities, months, and payment methods.

The dashboard provides interactive visualizations and key performance indicators (KPIs) to help users explore sales data and identify business trends.

## Tools and Technologies

- Microsoft Power BI Desktop
- Power Query for data transformation
- DAX (Data Analysis Expressions) for calculations
- CSV dataset

## Dashboard Features

- Total Sales
- Total Orders
- Average Order Value
- Sales by Product
- Sales by Category
- Sales by City
- Monthly Sales Trend
- Sales by Payment Method
- Interactive City and Category slicers

## Dataset Description

The project uses a supermarket sales dataset containing transaction-level information.

The dataset includes the following fields:

- Order ID
- Customer ID
- Customer Name
- Product
- Category
- Quantity
- Price
- Amount
- Order Date
- City
- Payment Method
- Order Status

The data is used to analyze sales performance and customer purchasing patterns.

## Business Objectives

The main objectives of this project are:

1. Calculate total sales and total orders.
2. Calculate the average order value.
3. Identify products and categories generating the highest sales.
4. Compare sales performance across cities.
5. Analyze monthly sales trends.
6. Compare sales across payment methods.
7. Provide interactive filters to explore the data by city and category.

## Key Business Insights

The dashboard helps analyze supermarket performance in the following areas:

- **Sales Performance:** Total sales and total orders provide an overview of business performance.
- **Product Performance:** The product sales chart helps identify products generating higher sales.
- **Category Performance:** The category chart helps compare sales across product categories.
- **City Performance:** The city chart helps identify locations contributing more to total sales.
- **Monthly Trends:** The monthly sales trend helps identify changes in sales over time.
- **Payment Methods:** The payment method chart compares sales across different payment types.
- **Interactive Analysis:** City and category slicers allow users to filter the dashboard and explore specific segments.

## Project Conclusion

This project demonstrates how Power BI can transform raw supermarket sales data into an interactive dashboard. It uses data visualization, DAX measures, and interactive filtering to support data-driven business analysis.

The project helped develop practical skills in data analysis, dashboard design, and business intelligence reporting.


## How to Run the Project

1. Download or clone this project repository.
2. Install Microsoft Power BI Desktop.
3. Open `Supermarket_Sales_Dashboard.pbix` in Power BI Desktop.
4. If prompted, update the dataset path or reconnect the data source.
5. Explore the dashboard using the City and Category slicers.
6. Review the KPI cards and charts to analyze supermarket sales performance.
